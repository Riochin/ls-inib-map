# updates/ — リリース告知素材

バージョンごとのX告知に使う素材置き場。1リリース ＝ フライヤー1枚 ＋ 投稿文1つ。

## 構成

| ファイル | 役割 |
|---|---|
| `announcement-template.md` | リリース告知 投稿文の定型（2.0スタイル）。新バージョンはこれをコピー |
| `ver○.○.flyer.html` | X投稿用の紹介画像（1200×675・スクショして使う） |
| `ver○.○.post.md` | そのバージョンの投稿本文 |
| `override-report-template.md` | 台数オーバーライド反映報告（提供者へのお礼）の定型。随時投稿 |
| `override-report-YYYY-MM.md` | その回の反映報告ドラフト |

## 新バージョンを出すとき

1. `announcement-template.md` をコピーして `ver○.○.post.md` を作り、目玉・熱量を埋める
2. `ver2.1.flyer.html` をコピーして `ver○.○.flyer.html` を作り、機能カードを差し替える
3. フライヤーをブラウザで開き `#flyer` 枠（1200×675）をスクショ
4. 投稿本文＋画像でXに投稿（タグは `#ラストサバイニブ #ジョジョLS #イニブ` 固定）
