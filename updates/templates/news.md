# サイト内お知らせ（新機能ページ）テンプレ

サイト内「お知らせ」＝オンボーディングの**新機能ページ**に出す文面の下書き。
Release announcement ワークフローが `updates/v○.○/news.md` に自動生成する。

確定したら **`src/data/releases.ts` の先頭にエントリを足して**サイトへ反映する
（この md はアーカイブ＋下書き、表示の出どころは `releases.ts`）。

## 形式（`releases.ts` の `Release` と対応）

- `version`: ○.○
- `date`: YYYY-MM-DD（公開日）
- `headline`: キャッチ。一部を紫で強調（`accent`）。
  例: 「もっと『正しい場所』に。」→ lead=「もっと」 / accent=「正しい場所」 / tail=「に。」
- `highlights`: 目玉機能。1つにつき「機能名（短く）」＋「説明1〜2文（ノンテック層にやさしく）」

## 下書き（コピー用）

```
ver ○.○（YYYY-MM-DD）
キャッチ: ［lead］【［accent＝紫強調］】［tail］

- ［機能名1］: ［説明1〜2文］
- ［機能名2］: ［説明1〜2文］
- ［機能名3］: ［説明1〜2文］
```

> トーンはオンボーディングに合わせる（平易・アイコン控えめ・専門語を避ける）。
> 断定できない数字・文言は `［要確認: …］` を残し、人手で確定する。
