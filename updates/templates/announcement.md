# リリース告知 投稿文テンプレ（X / 2.0スタイル）

ラストサバイニブのバージョン告知をXに投稿するときの定型。ver2.0の投稿が原型。
新バージョンを出すたびに、このテンプレをコピーして `updates/v○.○/post.md` を作る。
画像は同バージョンの `updates/v○.○/flyer.html` をスクショして添付する。

## スレッド構成（リリース時はリプツリーで出す）

リリース告知Xは**1スレッド**にまとめる。下の「型」が親ポスト、台数修正があればリプでぶら下げる。

```
親ポスト   ：【ver○.○】リリース告知（このテンプレ）
  └ リプ1 ：【台数情報修正】今回反映した台数  ← templates/override-report.md の親ポスト
      └ リプ2：お礼🙏 ＋ @メンション        ← templates/override-report.md のぶら下げリプ
```

- リプ1・リプ2の作り方・台数の起こし方・メンションの可否ルールは [`override-report.md`](override-report.md) に従う。
- そのリリースに `overrides.json` の修正が含まれないときは、親ポスト単体でOK（リプは付けない）。
- 親ポストにだけURL／ハッシュタグを載せ、リプ側は `override-report.md` の作法（URLなし）に合わせる。

## 型（コピー用）

```
【ver○.○】
ラスサバ・イニブ設置店舗マップ、［今回の目玉］🗾🎉

> > ［ビフォー］ → ［アフター］［絵文字］ <<

［開発の裏話・熱量を一言］‼️‼️

ラスサバ勢/イニブ勢の方、ぜひ！
https://ls-inib-map.vercel.app

#ラストサバイニブ #ジョジョLS #イニブ
```

## 各行の役割

| 行 | 役割 | ver2.0 実例 | コツ |
|---|---|---|---|
| `【ver○.○】` | バージョンの名札 | `【ver2.0】` | 毎回固定の頭。全角カッコ |
| 見出し | 目玉を一撃で | ついに全国対応しました🗾🎉 | `ついに〜`/`ようやく〜` で勢い、絵文字2個 |
| `> > A → B << ` ハイライト | 変化を数字で見せる**型の核** | `> > 関東260店 → 全国761店📍 <<` | 数字が伸びた所を1本。型の主役 |
| 熱量の一言 | 人間味・開発の背景 | 昨日ver1.0出したばかり…1日でめっっちゃ頑張りました‼️‼️ | 感情そのまま、`‼️`多用OK |
| 呼びかけ | 誰に向けてか | ラスサバ勢/イニブ勢の方、ぜひ！ | ほぼ固定文 |
| URL | 導線 | https://ls-inib-map.vercel.app | 常に固定 |
| タグ | 締め | `#ラストサバイニブ #ジョジョLS #イニブ` | 並び順まで固定 |

## 数字が伸びない改善回の `> > … << ` 差し替え

`A → B` が映えない回（パッチ・機能追加のみ）は、型（`> > … << `）を崩さず中身だけ変える:
- 機能で見せる: `> > 台数の"確からしさ"が見えるように👀 <<`
- 体験で見せる: `> > 「今日ペア戦？」が地図でわかる🗓️ <<`

これで改善回でも2.0の見た目・テンションを保てる。
