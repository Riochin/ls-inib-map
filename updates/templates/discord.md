# リリース告知 投稿文テンプレ（Discord / 2.1スタイル）

ラストサバイニブのバージョン告知を **Discordコミュニティ** に流すときの定型。ver2.1の投稿が原型。
新バージョンを出すたびに、このテンプレをコピーして `updates/v○.○/discord.md` を作る。
画像は同バージョンの `updates/v○.○/flyer.html` をスクショして添付する。

## X版との違い（先に方針）

| | X（`announcement.md`） | Discord（このファイル） |
|---|---|---|
| 読み手 | まだ知らない人＝拡散・発見 | すでにいる仲間＝コミュニティ |
| トーン | 勢い全開（`‼️` 連打） | 落ち着いて丁寧に1〜2発 |
| 絵文字 | Unicode（🗾🎉） | Discordショートコード（`:map:` `:bangbang:`） |
| 記法 | 素のテキスト | `##` 見出し・`-#` 小文字が使える |
| URL | `🔗 lsib.world` | `https://lsib.world/` |
| ハッシュタグ | 付ける（固定3つ） | 付けない |

## 型（コピー用）

```
## イニブ全国マップサイト、ver○.○リリースしました！:map:

［今回の目玉を平易に1文］:bangbang:

アップデート内容の詳細は、画像かサイトをチェックしてみてください:point_down::point_down:

https://lsib.world/

-# まだ訪問したことないよ〜って方も、この機会にぜひ！
```

## 各行の役割

| 行 | 役割 | ver2.1 実例 | コツ |
|---|---|---|---|
| `## …リリースしました！:map:` | バージョンの名札＋H2見出し | `## イニブ全国マップサイト、ver2.1リリースしました！:map:` | 毎回固定の頭。`##` と末尾 `:map:` は固定、`ver○.○` だけ差し替え |
| 目玉の一言 | 今回の目玉を**噛み砕いて** | 表示された台数が、どれほど正しいのか確認できるようになりました:bangbang: | コミュニティ向けに専門語を避けて1文、`:bangbang:` で締める |
| 誘導 | 画像/サイトへ送る | アップデート内容の詳細は、画像かサイトをチェックしてみてください:point_down::point_down: | ほぼ固定文。`:point_down:` ×2 |
| URL | 導線 | https://lsib.world/ | 常に固定。ドメインはX版と同じ lsib.world（表記だけ違う: X版は `🔗 lsib.world`、Discordは `https://lsib.world/`） |
| `-# …` 小文字の一押し | 新規さん・ご無沙汰さんへ | -# まだ訪問したことないよ〜って方も、この機会にぜひ！ | `-#`（Discordの小さいグレー文字）で柔らかく。ほぼ固定 |

## 数字が伸びた回の見せ方

X版の `> > A → B << ` ハイライトはDiscordでは使わず、**目玉の一言の中に数字を溶かす**:
- 数字で見せる: `関東260店から、ついに全国761店まで広がりました:bangbang:`
- 機能で見せる: `表示された台数が、どれほど正しいのか確認できるようになりました:bangbang:`

X版とテンションを変えつつ、伝える目玉は同じ回のものを使う。
