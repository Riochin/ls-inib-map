# ver2.4 サイト内お知らせ（新機能ページ・アーカイブ）

`src/data/releases.ts` の ver2.4 エントリと対応。テンプレは `templates/news.md`。

```
ver 2.4（2026-06-25）
キャッチ: 条件で【「絞り込む」】、ができるように。

- 設備条件フィルター: 配信台あり・録画台あり・喫煙所あり・営業中のみ・最低台数など、設備条件を指定して店舗を絞り込めるようになりました。
- 地方・複数都県選択: 「関東」「東北」といった地方区分や、複数の都県をまとめて選んで絞り込めるようになりました。
- 充実度フィルター: 情報が充実している店・不足している店だけを表示できます。データが足りない店を探して情報提供する際にも便利です。
```
