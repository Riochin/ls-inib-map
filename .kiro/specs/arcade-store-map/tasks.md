# 実装計画

- [x] 1. Next.jsプロジェクトの初期化と依存パッケージのセットアップ
  - Next.js (App Router) + TypeScriptでプロジェクトを作成する
  - Tailwind CSSを導入し、スマホファーストのベース設定を適用する
  - @vis.gl/react-google-mapsパッケージをインストールする
  - Google Maps APIキー用の環境変数（NEXT_PUBLIC_GOOGLE_MAPS_API_KEY）を設定する
  - パスエイリアス（`@/` → `src/`）を設定する
  - _Requirements: 6.1_

- [x] 2. 店舗データ層の構築
- [x] 2.1 (P) 店舗データの型定義を作成する
  - ゲームタイトル識別子（ラスサバ / イニブ）の型を定義する
  - 店舗データの型を定義する（ID、名称、住所、緯度経度、稼働タイトル）
  - フィルタ選択肢の型を定義する（すべて / ラスサバ / イニブ）
  - 1店舗は1つ以上のタイトルを持つという不変条件を型レベルで表現する
  - _Requirements: 4.1_

- [x] 2.2 公式サイトの情報をもとに静的な店舗データファイルを作成する
  - ラスサバ公式ページ（bandainamco-am.co.jp）から設置店舗の名称・住所を収集する
  - イニブ公式ページ（gundam-vs.jp）から設置店舗の名称・住所を収集する
  - 各店舗の住所から緯度経度を取得し、型付きの店舗データ配列としてまとめる
  - 両タイトルを稼働する店舗は、稼働タイトル配列に両方を含める
  - データはビルド時にバンドルされる静的ファイルとして配置する
  - _Requirements: 4.1, 4.2, 4.3, 4.4_

- [x] 3. (P) Google Maps地図表示の基盤実装
  - RootLayoutにAPIProviderを配置し、Google Maps APIを初期化する
  - MapPageコンポーネントを作成し、全画面で地図を表示する
  - 関東圏（東京周辺）を初期表示の中心座標・ズームレベルに設定する
  - 地図はピンチ操作によるズームとスワイプによる移動をサポートする（Google Maps標準機能）
  - クライアントコンポーネント（`'use client'`）として実装する
  - _Requirements: 1.1, 1.2, 1.4, 1.5_

- [x] 4. マーカー表示と店舗情報の実装
- [x] 4.1 店舗データからマーカーを地図上に描画し、タイトル別に色分けする
  - 静的店舗データを読み込み、各店舗の位置にAdvancedMarkerを配置する
  - ラスサバ単独店舗は紫色、イニブ単独店舗は緑色、両タイトル稼働店舗はオレンジ色のピンを使用する
  - マーカーの色はPinコンポーネントで稼働タイトルに応じて動的に設定する
  - _Requirements: 1.3, 2.4_

- [x] 4.2 マーカータップで店舗の詳細情報をInfoWindowに表示する
  - マーカーをタップすると、店舗名・住所・稼働タイトルを含むInfoWindowを表示する
  - useAdvancedMarkerRefフックでマーカーとInfoWindowを接続する
  - InfoWindowの開閉状態を管理し、他のマーカーをタップした際は前のInfoWindowを閉じる
  - _Requirements: 2.1, 2.2, 2.3_

- [x] 5. フィルタリング機能の実装
- [x] 5.1 タイトル別フィルタリングUIを作成する
  - 「すべて」「ラスサバ」「イニブ」の3つのフィルタボタンを地図上部にオーバーレイ配置する
  - 現在選択中のフィルタをハイライト表示する
  - タッチターゲットは44px以上を確保し、地図表示を大きく妨げないコンパクトなデザインにする
  - _Requirements: 3.1, 5.2, 5.3_

- [x] 5.2 フィルタ状態に基づく店舗データの絞り込みロジックを実装する
  - MapPageでフィルタ状態（すべて / ラスサバ / イニブ）をuseStateで管理する
  - フィルタ切替時に、選択タイトルに該当する店舗のみをMapViewに渡す
  - 「すべて」選択時は全店舗を表示する
  - 初期状態では「すべて」のフィルタが選択された状態とする
  - 両タイトルを稼働する店舗はどちらのタイトルフィルタでも表示する
  - _Requirements: 3.2, 3.3, 3.4, 3.5_

- [x] 6. モバイル最適化とビルド検証
  - 画面全体を地図が占有し、フィルタUIがオーバーレイされるモバイルファーストレイアウトを確認する
  - 375px幅以上のビューポートで全機能が正しく動作することを確認する
  - `npm run build`でビルドが成功し、外部APIサーバーへの依存がないことを確認する
  - Vercelデプロイに必要な設定が揃っていることを確認する
  - _Requirements: 5.1, 5.2, 5.3, 5.4, 6.1, 6.2, 6.3_
