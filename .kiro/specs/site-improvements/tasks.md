# 実装計画

> **アーキテクチャ境界**: 本計画は設計書の2つの独立境界に沿う。**(B) クライアント地図描画**（`src/`、タスク2〜6）と **(A) ビルド前データ生成パイプライン**（`scripts/`・`.github/`、タスク7〜12）は、生成物 `stores.json` のデータ契約のみで結合する。タスク1（型・契約の基盤）完了後、両境界は並行着手できる（`(P)` 参照）。

> **開発プロセス規約（全タスク共通・Req 8.1, 8.2, 8.3, 8.4）**: 各サブタスクは独立して着手・検証可能な粒度に保つ。1サブタスク完了ごとにその単位でコミットし、無関係な変更を同一コミットに混在させない。コミットメッセージは既存規約（`feat:` / `fix:` / `chore:` プレフィックス + 日本語要約）に従う。
